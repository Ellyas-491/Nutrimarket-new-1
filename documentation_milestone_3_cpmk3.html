Ringkasan Eksekutif:
Dokumen ini menyajikan bukti implementasi dan penjelasan teknis mendalam mengenai arsitektur perangkat lunak pada aplikasi NutriMarket. Pembahasan mencakup 3 aspek utama panduan pengerjaan: (1) Pemilihan pustaka State Management standar industri Provider, (2) Penerapan Clean Architecture dengan pemisahan tegas antara Layer Presentation, Domain/Business Logic, dan Data, serta (3) Pengendalian interaksi UI terhadap status dinamis (Initial, Loading, Empty, Success, Failure) pada alur Keranjang Belanja (Cart Flow), Langganan Premium (Subscription/Paywall Flow), dan Katalog Produk. Seluruh bagian dilengkapi dengan rujukan lokasi direktori dan cuplikan kode sumber nyata dari proyek.

1. Pilihan Pustaka State Management Standar Industri: Provider

1.1 Alasan Pemilihan & Karakteristik Provider

Untuk mengelola state aplikasi secara efisien dan terstruktur, proyek NutriMarket menggunakan pustaka Provider (v6.1.2). Provider merupakan pustaka manajemen state resmi yang direkomendasikan secara langsung oleh tim pengembang Flutter di Google karena alasan-alasan teknis berikut:

  • Standar Industri & Kompatibilitas Ekosistem: Provider membungkus mekanisme bawaan InheritedWidget menjadi API yang sangat intuitif, deklaratif, dan aman dari memory leak.
  • Implementasi Observer Pattern: Memisahkan antara subjek penyedia data (ChangeNotifier) dengan pengamat (Widget listener), sehingga mutasi data tidak memerlukan manipulasi langsung pada widget UI.
  • Pembersihan & Optimasi Rebuild: Provider hanya me-rebuild sub-tree widget yang secara eksplisit mendengarkan perubahan data, mencegah jank dan rebuild global yang boros sumber daya.
  • Testability: Service layer yang dibuat terlepas dari konteks UI, mempermudah pengujian Unit Testing tanpa perlu mem-boot simulator UI.

1.2 Registrasi Sentral MultiProvider pada Root Aplikasi

Seluruh penyedia layanan (service providers) didaftarkan pada root widget tree menggunakan MultiProvider di file utama aplikasi:

1.3 Pola Resolusi State di Widget (Watch vs Read vs Consumer)

Metode Resolusi Mekanisme Kerja Contoh Pemakaian di Proyek
context.watch<T>() Mendaftarkan widget sebagai active subscriber. Widget akan di-rebuild otomatis saat notifyListeners() terpanggil. HomeScreen mendengarkan update daftar katalog produk di ProductRepository.
context.read<T>() Mengambil referensi instance service tanpa mendaftarkan listener (tidak memicu rebuild). Dipanggil dalam event handler tombol aksi: onPressed: () => context.read<CartService>().addToCart(p).
AnimatedBuilder / Consumer Membungkus area spesifik widget tree yang membutuhkan update lokal. Badge counter keranjang belanja dan kartu total kalkulasi harga di CartScreen.

2. Penerapan Struktur Clean Architecture (3 Layers)

Arsitektur aplikasi NutriMarket dirancang dengan prinsip Clean Architecture untuk memisahkan tanggung jawab antarmuka, aturan bisnis, dan akses data. Pembagian lapisannya adalah sebagai berikut:

1. Presentation Layer (UI & Widgets) Lokasi: lib/features/*/screens/ & lib/features/*/widgets/

Bertanggung jawab mutlak atas visualisasi data, tata letak antarmuka, animasi, serta penerimaan input pengguna. Layer ini tidak boleh mengandung query database atau logika bisnis langsung; seluruh aksi pengguna didelegasikan ke Domain Layer melalui Provider.

2. Domain / Business Logic Layer (Services & Repositories) Lokasi: lib/features/*/services/

Menampung seluruh aturan bisnis aplikasi: kalkulasi harga subtotal dan ongkos kirim, validasi status kupon/diskon premium, mutasi keranjang belanja, manipulasi status pesanan, serta manajemen antrean sinkronisasi offline. Menggunakan ChangeNotifier untuk memicu pembaruan state reaktif.

3. Data Layer (Models, Local Storage, & Remote API) Lokasi: lib/data/ & lib/features/*/models/

Mengelola akses data mentah baik dari cloud (Supabase PostgreSQL & Auth) maupun perangkat lokal (SharedPreferences & FlutterSecureStorage). Mengubah data JSON/Map menjadi entity model Dart dan menangani caching persisten offline-first.

2.2 Bukti Pemisahan Logika Bisnis dari UI pada CartService

Potongan kode berikut membuktikan bahwa perhitungan harga, penambahan item, persistensi cache lokal, dan antrean sinkronisasi cloud diproses murni di Domain Layer tanpa menyentuh widget UI:

Lokasi Kode: lib/features/cart/services/cart_service.dart (Baris 14 - 32, 113 - 153)
class CartService extends ChangeNotifier {
  final List<CartItem> _items = [];

  List<CartItem> get items => List.unmodifiable(_items);
  int get itemCount => _items.fold(0, (sum, item) => sum + item.quantity);
  double get subtotal => _items.fold(0, (sum, item) => sum + item.totalPrice);
  double get deliveryFee => _items.isEmpty ? 0 : 10000;
  double get total => subtotal + deliveryFee;

  // Logika Bisnis: Tambah Produk ke Keranjang
  void addToCart(FoodProduct product, {int quantity = 1, String sellerNotes = ''}) {
    final index = _items.indexWhere((item) => item.product.id == product.id);
    if (index >= 0) {
      _items[index].quantity += quantity;
    } else {
      _items.add(CartItem(product: product, quantity: quantity, sellerNotes: sellerNotes));
    }

    // 1. Simpan ke Cache Lokal (Data Layer)
    _persistLocalCart();

    // 2. Masukkan ke Antrean Sinkronisasi Cloud Offline-First
    LocalStorageService().addToSyncQueue({
      'id': 'task_cart_${product.id}',
      'type': 'cart_item',
      'payload': {'product_id': product.id, 'quantity': quantity},
    });
    OfflineSyncService().triggerSync();

    // 3. Pemicu Update Reaktif UI
    notifyListeners();
  }
}

Future<void> _activatePremium() async {
  // 1. Update State Domain & Local Storage Cache
  final historyService = HistoryService();
  final updated = historyService.userProfile.copyWith(isPremium: true);
  historyService.updateUserProfile(updated, notifyUser: false);
  LocalStorageService().saveUserProfile(updated.toMap());

  // 2. Sinkronisasi Data ke Supabase Cloud Backend
  final supabase = SupabaseService();
  if (supabase.isConfigured && supabase.currentUser != null) {
    try {
      await supabase.client!.from('profiles').upsert({
        'id': supabase.currentUser!.id, 
        'is_premium': true
      });
    } catch (e) {
      debugPrint('[Paywall] Error syncing premium: $e');
    }
  }

  // 3. Buat Notifikasi & Feedback SUCCESS ke UI
  NotificationService().addNotification(
    title: 'Nutri Market Plus Aktif 👑',
    message: 'Langganan aktif. Nikmati diskon 10% dan AI tanpa batas.',
    category: NotificationCategory.promo,
    isImportant: true,
  );

  setState(() {});
  if (mounted) {
    AppToast.show(
      context,
      title: 'Nutri Market Plus Aktif! 👑',
      subtitle: 'Selamat! Diskon 10% di keranjang belanja dan Konsultasi AI Pro telah aktif.',
      type: ToastType.success,
    );
  }
}
